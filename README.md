<details>
<summary>📖 Deep Dive: How the 3D magic works</summary>

<br>

The 3D experience is powered by **Three.js**:

- 🌠 **Starfield** — 1400 particles rendered via `THREE.Points` drifting in 3D space
- 🧊 **Neon shapes** — Wireframe icosahedrons floating with sine-wave motion
- 🎥 **Parallax camera** — Camera eases toward mouse position for depth illusion
- 🌀 **Hero objects** — Separate mini-scenes render cube, torus & sphere simultaneously

All rendering happens on a fixed full-screen `<canvas>` behind the content, with `requestAnimationFrame` powering a buttery-smooth loop.

</details>
